# Etüt — yasal metinler

Bu depo **üretilmiştir, elle yazılmaz.**

- <https://berkayberatsonmez.github.io/etut/> — gizlilik politikası
- <https://berkayberatsonmez.github.io/etut/hesap-silme.html> — hesap silme talebi

Kaynak, Etüt'ün özel geliştirme deposunda `docs/legal/yayin/` altında durur ve
`tool/yayin_uret.py` bu sayfaları oradan üretir. Üretici, yayımdan önce çıktıyı
tarar: canlı davet kodu, hesap kimliği deseni ya da izinsiz bir e-posta adresi
bulursa **yayımı durdurur**.

Buradaki bir dosyayı elle düzenlemek, bir sonraki üretimde geri alınır.
